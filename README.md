# Barber Shop Management System Using Machine Learning for Sales Forecasting and Customer Sentiment Analysis

A web-based management system developed for Supremo Barbershop in Caloocan City. The system aims to improve daily barbershop operations through appointment scheduling, sales monitoring, customer feedback analysis, and machine learning-based sales forecasting.
